# CircuitForge Lab

Interactive electronics learning lab built with Vue, Vite and Three.js.

## Features

- Interactive 3D workbench with orbit and zoom controls.
- Guided lessons for Ohm's law, resistor color codes, series/parallel circuits, logic gates, inverters and transistors.
- Practice presets with live educational readings.
- Responsive layout for students and adults.

## Development

```bash
npm install
npm run dev
```

Build for production with `npm run build`.
